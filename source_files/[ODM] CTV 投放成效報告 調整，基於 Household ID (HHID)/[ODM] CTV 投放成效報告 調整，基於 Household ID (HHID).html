背景說明 ：

  • Household ID (HHID) 說明：

    • 定義：家戶 CTV 裝置 ID，OneDATA 內部技術使用 hashID (IP+useragent)，欄位名稱為 xx_uaip

    • 標籤 (年齡性別、興趣) 來源：藉由 IP 當作 Key 值，比對 CTV 裝置外的家庭成員標籤，再將標籤歸戶至 HHID (備註1)

  • CTV-pre-roll 格式使用 HHID 投放，承上説明 HHID 本身會帶著多個年齡性別標籤，因為一個家戶可能會有多個年齡性別組合 (備註2)

調整原因 ：別於其他格式每個廣告查詢只會有一個年齡性別，在投放 CTV-pre-roll 廣告時，會產生一個查詢比對到多個年齡性別的情形，會造成投放成效報告錯亂

投放邏輯說明 ：

  • ctv-pre-roll 年齡性別僅會判斷 user_des 欄位， user_de 為 CTV-pre-roll 以外的格式使用

  • camp_de 為 campaign 指定的年齡性別

  • des 為 user_des 與 camp_de 交集的年齡性別 (不會比對 user_de )

  • user_des, des 為本次新增欄位

需求1 - ODM 需要調整有呈現年齡性別的相關報表 ：

  • 報表1：廣告活動 > 廣告成效 > 受眾報告數據 > 年齡性別

  • 報表2：投放項目設定 > 投放成效報告 > 受眾報告數據 > 年齡性別

  • 小數點歸戶邏輯待確認

需求2 - Unique User 需要調整為 Unique HHID ：

  • 當裝置為 CTV，Unique User 需要改為 Unique HHID

  • Unique HHID 計算邏輯為 count(distinct xx_uaip )

  • ARE-1225 - 取得議題詳細資料... 狀態

  • 呈現位置：

    • 廣告活動 > 廣告成效 > 整體活動成效

    • 投放項目設定 > 投放成效 > 整體活動成效

    • 備註：走期結束才會出現 Unique User / Unique HHID (原邏輯，非此次異動)
