🔸 註冊頁面

  • 網址欄位新增提示 icon

  • hover / click 顯示：

請確認您申請的網站支援嵌入 Javascript，由於 OneAD 廣告代碼使用此語法。請注意，Facebook、Instagram、Threads、LINE、YouTube、TikTok 和 Discord 等平台不支援 Javascript 嵌入，因此無法接受來自這些平台的申請。

  • 網域驗證功能

  • 禁止下列平台開頭的網址（前綴比對）：

  • https://www.facebook.com/

  • https://www.instagram.com/

  • https://www.threads.net/

  • https://www.youtube.com/

  • https://discord.com/

  • https://www.tiktok.com/

  • https://www.twitch.tv/

  • 若輸入上述網址應出現錯誤提示：「不支援此平台網址，請使用可嵌入 JS 的網站」
