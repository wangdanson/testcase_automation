資料計算邏輯

數據計算

  1. 依據 version 將 daily row data 資料區分出來

    • example

      • 資料 id= 24999 && start_date>= 2020-11-17 && end_date<= 2020-11-18

      • 資料 interests in [601, 602] , 其他皆為 0 （others）

      • 所有項目(cv, impression…)數值都為 0 的資料直接剔除不用處理

  2. 將 version 區分出來的 daily row data 資料進行權重計算

    • 將 others 數值依據權重分配給 interests

    • 權重計算公式： FLOOR(all_dataset * dataset / sum(dataset))

      • example:

      • ig 601 cv 權重計算 = FLOOR((9968+9912+275) * 9968 / (9968+9912))=10105

      • ig 602 cv 權重計算 = FLOOR((9968+9912+275) * 9912 / (9968+9912))=10049

  • 將 version 區分出來的 group row data 資料與初步權重整理完的 daily row data 進行權重計算

    • 將 group row data 數值依據權重分配給 daily row data

    • 權重計算公式： FLOOR(group_dataset * daily_dataset / sum(daily_dataset))

      • example:

      • ig 601 cv 權重計算 = FLOOR(42597 * 10105 / (10105+10049))=21357

      • ig 602 cv 權重計算 = FLOOR(42597 * 10049 / (10105+10049))=21239

  • 權重計算無條件捨去的差異值，需加到該 version 最小的數值

    • 找出該 version 相對應項目最小數值( Min(...) )

    • 將差異值加到該項目數值， Min(cv)+(group_dataset-sum(權重計算結果))= Min(cv)+(42597-(21357+21239))

    • 若有多筆相等的最小值，則將差異值依據 ig 排序小 -> 大，依序 +1 分配，直到差異值歸 0 為止

  • 將所有 version 的權重計算結果依據 id ＆ ig & 項目(例如：cv)加總，作為 API response
