數據計算

  • 依據 version 將 row data 資料區分出來

    • example

      • 資料 id= 34104 && start_date>= 2021-07-01 && end_date<= 2021-07-01

      • 資料 demographics in [4, 6] , 其他皆為 0 （others）

  • 將 version 區分出來的資料進行權重計算

    • 將 others 數值依據權重分配給 demographics

  • version 權重計算公式： FLOOR(all_dataset * dataset / sum(dataset))

    • example: user_de 4 cv 權重計算 = FLOOR((352+1341+9) * 352 / (352+1341))=353

  • 權重計算無條件捨去的差異值，需加到該 version 最小的數值

    • 找出該 version 相對應項目最小數值( Min(...) )

    • 將差異值加到該項目數值， Min(cv)+(all_dataset-sum(權重計算結果))= Min(cv)+((352+1341+9)-sum(權重計算結果))

    • 若有多筆相等的最小值，則將差異值依據 user_de 排序小 -> 大，依序 +1 分配，直到差異值歸 0 為止

  • 將所有 version 的權重計算結果依據 id ＆ user_de & 項目(例如：cv)加總

  • 校正回歸 計算結果若男女量體差別過大時，要調整差距到 < 60%，調整的級距是一次 5%

    • 將男女年紀區間 id 分組

    • 判斷該組男女 impression 資料最大值是否超過總值 60%

      • example: user_de [5, 6]，Max (68145, 27612) = 68145

      • 找出 Max user_de = 68145 -> 5, Min -> 6

      • 68145/(68145+27612)=0.7116 大於 0.6 ，表示需要校正回歸

      • 校正回歸

        • 每次調整級距 0.05 ，68145*級距 <= (68145+27612)*0.6 ，因此級距為0.8

        • 每個數值(cv, impression…)以該級距調整

          • 6 impression = Min(68145, 27612)+(Max(68145, 27612)*1-0.8)

          • 5 impression = Max(68145, 27612)*0.8

        • 無條件捨去的差異值，需加到最小的數值
