📖 項目概述

📌 項目背景

SuperDSP 過往所有素材建立流程皆在平台內處理，導致因應新格式需求時，前端、後端、MTO 皆需反覆開發與調整，增加了跨部門 loading 與維護風險。為了提升擴展彈性並降低內部負擔，將導入 Studio 系統作為主要素材管理平台。

🎯 項目目標

  • 將素材建立流程導流至 Studio，支援快速上線新廣告格式

  • 在 SuperDSP 的素材管理頁新增「建立更多素材」按鈕

  • 導入跳轉至 Studio 建立素材包的流程（帶入 user token）

  • 將追蹤碼設定邏輯由素材包階段改為 Placement 階段

  • 根據合約格式自動判斷格式來源（Studio / 系統原生），進行功能切換

🧩 項目範圍

包含：

  • SuperDSP UI 增設「前往 Studio 建立素材」按鈕並導向 Studio（名稱暫定）

  • 跳轉到 OneAD Studio 時候，需新開畫面後透過後端 redirect 到 OneAD Studio

  • 修改 Placement 建立流程支援設定追蹤碼

  • 格式識別邏輯與 UI 行為 （Studio 格式需要新開畫面並轉址到對應格式建立畫面）

  • Studio 系統內部素材建立流程，移出設定追蹤碼功能

不包含：

  • 原生 SuperDSP 格式的 UI / 欄位邏輯變動

🗺️ Mermaid 流程圖

🎯 使用場景說明

主要包含四種使用情境：

  1. 從素材管理頁點擊「前往 Studio 建立素材」導向行為

  2. 使用者欲建立素材包時，選擇 Studio 格式並導向 Studio 建立頁

  3. 素材管理頁列表中的 Studio 欄位 不可編輯 ，只能查看已使用項目

  4. 建立廣告組合時選擇 Studio 格式，禁用素材包建立按鈕並提示

並對應每種情境中的異常處理，如：token 取得失敗、使用者取消跳轉等狀況。
－－

✅ 情境一：透過 “前往 STUDIO 建立素材“ 進入 STUDIO，並建立素材包

✅ 情境二：透過 “預覽 / 編輯 / 複製“ 按鈕進入 STUDIO，並對素材包進行操作

✅ 情境三：透過 "新增素材包" 選擇 STUDIO 格式，進入 STUDIO 系統，並進行素材包建立

✅ 情境四：透過新增投放條件，建立 STUDIO 素材，並選擇素材包

📡 API 與技術整合

🔑 Studio Redirect API

  • Endpoint： /studio/redirect

  • 參數：token, clientId, universalId（格式 ID 可選）

  • 回傳：302 Redirect 至 Studio 對應畫面

📩 使用 postMessage 接收回傳

  • Studio 建立完成後呼叫： 

window.opener.postMessage({ type: "studioPackageCreated", packageId: "123456" }, "*")

  • SuperDSP 接收端需綁定監聽： 

window.addEventListener("message", (e) => {
  if (e.data.type === "studioPackageCreated") {
    const newPackageId = e.data.packageId;
    // 自動帶入或刷新素材列表
  }
});

🧩 開發注意事項

  • 所有 Studio 跳轉動作均須以新視窗方式開啟，透過後端 redirect 到 OneAD Studio

  • API 失敗應提供友善錯誤提示，並避免卡死在 loading 狀態

  • 若 Studio 無法跳出視窗（例如瀏覽器擋彈窗），建議引導使用者手動開啟連結

  • 所有互動建議補上 Tooltip 或導引文案，提升流程理解
