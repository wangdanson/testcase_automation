本測試用例涵蓋 SuperDSP 中所有觸發 STUDIO 素材導流功能的情境，包括：

  • 素材管理頁的建立 / 預覽 / 編輯 / 複製

  • 廣告組合建立流程中選擇 Studio 素材格式與導流行為

供 QA、前端、後端及 PM 進行驗證作業。

📘 前置條件

  • 測試帳號已登入 SuperDSP 並具素材與廣告組合建立權限

  • STUDIO 系統測試環境可正常導入

  • 測試素材已包含至少一筆 STUDIO 來源素材包

  • /studio/redirect API 已部署並可用

📦 素材管理導流操作測試

測試項目

操作路徑

預期結果

建立 Studio 素材

點擊「前往 Studio 建立素材」

  1. 出現 Message Box：「將以開新視窗方式，帶您前往 STUDIO」

  2. 正常跳轉 Studio 建立畫面

建立 Studio 素材

點擊「新增素材包」，於”選擇格式”欄位選擇 OneAD Studio 才有的格式

  1. 出現 Message Box：「將以開新視窗方式，帶您前往 STUDIO」

  2. 抽屜收合

  3. 正常跳轉 Studio 該格式建立畫面
    例外狀況：該格式在 Studio 有多對個對應格式，則會跳轉到 Studio 選擇格式畫面，並會 filter 顯示該格式在 Studio 有多對個對應格式

預覽 Studio 素材

點擊「預覽」按鈕

  1. 出現 Message Box：「將以開新視窗方式，帶您前往 STUDIO」

  2. 跳轉至 Studio 素材預覽畫面

編輯 Studio 素材

點擊「編輯」按鈕

  1. 出現 Message Box：「將以開新視窗方式，帶您前往 STUDIO」

  2. 跳轉至 Studio 素材編輯畫面

複製 Studio 素材

點擊「複製」按鈕

  1. 出現 Message Box：「將以開新視窗方式，帶您前往 STUDIO」

  2. 跳轉至 Studio 素材複製畫面
