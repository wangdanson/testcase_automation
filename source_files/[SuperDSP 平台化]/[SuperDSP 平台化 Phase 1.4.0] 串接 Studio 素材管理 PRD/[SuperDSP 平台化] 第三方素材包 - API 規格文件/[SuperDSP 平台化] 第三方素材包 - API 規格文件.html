name

創建第三方素材包 API

methods

Post

path

/api/v1/advertisers/:advertiser_id/material/external_packs

status

新 API

開發狀態

request type 

header
{
  Authorization: string, required: true
  X-User: string, required: true
}

body
{
  "title": string, 必填
  "source_id": string, 必填, # binding occ id
  "ad_format_id": integer, 必填,
  "ad_format_type_id": integer, 必填
  "vast_feature": enum string, ['NONE', 'VAPID', 'SIMID']
  "source": enum string
  "description": string, default: ""
  "ron": boolean
  "content": string
}

request sample 

header
{
  Authorization: 'a123f'
  X-User: 'abcde'
}

body
{
  "title": "ssssss",
  "source_id": "507f191e810c19729de860ea",
  "ad_format_id": 1,
  "ad_format_type_id": 1,
  "vast_feature": "NONE",
  "source": "superdsp",
  "description": "",
  "ron": false,
  "content": "aaaaa"
}

controller

app/controllers/api/v1/material/external_packs_controller.rb

response 

{
