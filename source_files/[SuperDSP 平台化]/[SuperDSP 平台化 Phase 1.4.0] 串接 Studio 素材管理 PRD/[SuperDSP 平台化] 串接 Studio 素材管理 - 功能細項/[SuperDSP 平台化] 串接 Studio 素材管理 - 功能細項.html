  • Pack 列表頁

  • Video 列表頁

  • Banner 列表頁

  • 來源類型 ：SuperDSP / OneAD Studio

  1. Studio 建立素材包產生的 Video 在 Video 列表中來源欄位顯示 OneAD Studio。

  2. Studio 建立素材包產生的 Banner 在 Banner 列表中來源欄位顯示 OneAD Studio。

  3. Studio 建立的素材包在 Pack 列表中來源欄位顯示 OneAD Studio。

  4. 在 SuperDSP 平台上傳的 Video / Banner，在列表來源來為顯示 SuperDSP。

  5. 在 SuperDSP 平台建立的素材包，在列表來源來為顯示 SuperDSP。

Studio 素材操作功能

素材管理

  • Pack 列表頁

  • Video 列表頁

  • Banner 列表頁

  • 「預覽」：功能與原先相同。(開啟預覽抽屜)

  • 「編輯」：狀態變更為 disabled

  • 「預覽」：彈出確認通知窗

通知窗：
  標題：通知
  內容：將以開新視窗方式，帶您前往 STUDIO
  行為：
    是：向後端取得跳轉連結，取得後開新標籤頁跳轉到 Studio。

  3. 點擊『編輯，彈出跳轉通知確認窗。

  4. 承 6，點擊 確認 ，開新頁籤進入 Studio 指定素材包編輯頁面。

  5. 點擊『複製，彈出跳轉通知確認窗。

  6. 承 8，點擊 確認 ，開新頁籤進入 Studio 素材包列表，並彈出複製功能彈窗。

Studio 格式選擇功能

素材管理 - 新增素材包

  • 新增 Studio 格式

    • 樣式：Button (與 radio 風格類似，加上邊框，移除右上角圖示，詳見備註)

    • 點擊行為：彈出確認通知窗 

通知窗：
  標題：通知
  內容：將以開新視窗方式，帶您前往 STUDIO
  行為：
    是：向後端取得跳轉連結，取得後開新標籤頁跳轉到 Studio，並關閉抽屜。
    不，停留在此：關閉彈窗。

  • SuperDSP 格式的素材選擇，可選擇 Studio 產生的 Videio 與 Banner 素材。

  • 情境：

    • 廣告品類下的格式只有 Studio：

      • 選擇該廣告品類，彈出確認通知窗。

      • 彈窗選擇 不，停留在此 關閉彈窗，但抽屜內不會有影片與 Banner 可以選擇，也無法儲存，只提供選擇格式來再次開啟通知彈窗。

    • 廣告品類下的格式有 SuperDSP 與 Studio：

      • SuperDSP 格式會在最左邊，再來才是 Studio 格式 (後端會進行排序；避免前端因預設選擇第一個格式，導致明明有非 Studio 的選項卻讓使用者一進入就有機會觸發跳彈窗機制)

  1. 選擇 SuperDSP 格式，格式會變更為選取狀態。

  2. 選擇 Studio 格式，彈出跳轉通知確認窗。

  3. 承上，點擊確認，關閉新增素材包抽屜，並開新頁籤進入 Studio 指定格式建立的頁面。

  4. 在 Studio 完成建立後，SuperDSP 應自動重新取得列表資料。

  5. [RichMedia 只有 Studio 格式] 點擊『RichMedia』，彈出跳轉通知確認窗。

  6. 承上，點擊 確認 ，關閉新增素材包抽屜，並開新頁籤進入 Studio 指定格式建立的頁面。(因進入預選第一個格式的關係)

  7. 承 5 ，點擊 不 ，關閉彈窗，抽屜內沒有影片與 Banner 選擇器，無法儲存。

  8. 承 7 ，點擊任一格式，彈出跳轉通知確認窗。

後端會增加 perdsp_enabled ，讓前端判斷是否為 Studio 的格式

  • superdsp_enabled = true ：SuperDSP 格式

  • superdsp_enabled = false ：Studio 格式

Instream 原本設計就沒有格式可以選擇，且本次開發預計添加的格式沒有 Instream 系列，所以沒特別調整，若後續有加入 Insteam 格式，前端需要進行處理，否則格式無法顯示。

廣告組合 - 新增/編輯廣告組合

  • 新增 Studio 格式

    • 樣式：Radio (與 SuperDSP 格式相同)

    • 點擊行為：格式變更為選取狀態

  • 選擇的格式若為 Studio，點擊新增素材包，顯示通知彈窗 

通知窗：
  標題：通知
  內容：將以開新視窗方式，帶您前往 STUDIO
  行為：
    是：向後端取得跳轉連結，取得後開新標籤頁跳轉到 Studio。
    不，停留在此：關閉彈窗。

  • 展開『指定素材包』選單時，再次透過 API 取得選單資料。(讓使用者可以即時選到 Studio 素材)

  1. 選擇 SuperDSP 格式，點擊『新增素材包』，開啟新增素材抽屜。

  2. 承上，完成素材包建立後，自動關新增素材抽屜，建立的素材包會自動帶入指定素材包。

  3. 選擇 Studio 格式，點擊『新增素材包』，彈出跳轉通知確認窗

  4. 承上，進入 Studio 後，要顯示指定格式建立的頁面。

  5. 承上，完成素材包建立後，回到 SuperDSP 頁籤並展開素材選單，要顯示 Studio 建立的素材包選項。

追蹤碼與格式設定

素材管理 - 新增 / 編輯素材包

廣告組合 - 新增 / 編輯廣告組合

  • 素材包移除『追蹤碼』設定

  • 廣告組合新增『追蹤碼』設定

    • 移除原先建立筆數限制

    • 功能

      • 輸入區域驗證：

        • 輸入：符合規範的 URL

        • 貼上：

          • Pixel Tracking Code (會擷取追蹤碼的 URL，帶入 input 中)

          • 符合規範的 URL

      • ＋ 按鈕：新增一筆空白追蹤碼輸入

      • 刪除按鈕：

        • 刪除該筆追蹤碼

        • 數量為一時，按鈕狀態變更為停用

    • 位置：地區下方 (待定)

  1. 『新增 / 編輯素材包』無追蹤碼設定。

  2. 可成功建立素材包。 ( Insteam / RichMedia / Quality Traffic )

  3. 『新增 / 編輯廣告組合』有追蹤碼設定。

  4. 貼上 Pixel Tracking Code 會自動擷取出 url 部分帶入 input。

  5. 貼上不符合規範的 URL 與 Pixel Tracking Code 顯示警告訊息。

  6. 輸入不符合規範的 URL，blur 後顯示警告訊息。

  7. 未設定追蹤碼，要能成功建立廣投放條件。( Insteam / RichMedia / Quality Traffic )

  8. 點擊 + 按鈕，新增一筆無資料的追蹤碼項目

  9. 追蹤碼刪除剩下一筆時，刪除按鈕狀態變更為停用，無法再移除。

  10. 新增多筆追蹤碼項目，只在部分填寫 URL，儲存後只保留有資料的項目。

  • Studio 格式設計會提供格式縮圖
