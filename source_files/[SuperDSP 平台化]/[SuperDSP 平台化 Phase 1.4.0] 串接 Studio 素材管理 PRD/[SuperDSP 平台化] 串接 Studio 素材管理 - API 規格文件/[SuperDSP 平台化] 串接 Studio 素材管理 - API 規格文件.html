API 規格

Redirect

按一下此處以展開...

name

前往 OneAD Studio

methods

GET

path

api/v1/superdsp/companies/#{company_id}/redirect/studio

status

新 API

開發狀態

request type 

header
{
  "Authorization": string, required: true
}

path
company_id # 必填

query
action_type # [create / copy / edit / preview]
pack_id # action_type 為 copy / edit / preview 必填
ad_format_type_id # 選填

request sample 

header
{
  "Authorization": "abcde"
}

controller

app/controllers/api/v1/users_controller.rb

response 

{
  status: 'success',
  data: 'url'
}

who

備註

  1. 使用 JWT 產出一組 token 

{
  "user_id"
  "source": 'SuperDSP'
  "exp": Time.now.to_i + 1.day.to_i
}

  1. redirect page with access token

  2. 帶入參數：

    1. packageID: 素材包 ID

    2. clientID: 目前使用者所選擇的廣告主 ID

    3. ad_format_type universal id
