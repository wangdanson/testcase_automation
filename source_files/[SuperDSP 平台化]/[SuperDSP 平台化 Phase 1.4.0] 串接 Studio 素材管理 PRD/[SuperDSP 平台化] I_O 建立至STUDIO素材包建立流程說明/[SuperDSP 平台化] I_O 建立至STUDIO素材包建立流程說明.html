本文件說明使用者於 SuperDSP 系統中，從建立 I/O 單至完成廣告組合所需素材流程的完整操作路徑，並標註 Studio 格式導流的特殊邏輯與注意事項，供前端、後端與 PM、QA 團隊參考。

✅ 完整操作流程步驟

1️⃣ 登入與建立 I/O 單

  1. 用戶登入 SuperDSP 系統

  2. 前往【I/O 單管理】

  3. 點擊「新增 I/O 單」

  4. 填寫：

    • I/O 單名稱

    • 廣告目的：Brand Building（可選：Brand Building / Drive Traffic / Push Conversion ）

    • 選擇產業主/子類型

2️⃣ 建立廣告活動

  1. 點擊「新增廣告活動」

  2. 填寫：

    • 廣告活動名稱

    • 廣告品類：RichMedia（可選：InStream / RichMedia）

    • 廣告走期

    • 預算

3️⃣ 建立廣告組合

  1. 點擊「新增廣告組合」

  2. 填寫：

    • 廣告組合名稱

    • 選擇數據鎖定

    • 選擇格式：如 MIB Flash - MIB Flash Hit Banner

📦 Studio 格式素材包處理情境

✅ 已有素材包（預先於 Studio 建立）

  • 在「指定素材包」欄位中可選擇該 OneAD Studio 素材包

  • 完成其他欄位（走期、計價單位等）後儲存完成

❌ 無對應素材包（尚未建立）

  • 「指定素材包」下拉選單找不到目標格式素材包

  • 「新增素材包」按鈕點擊後顯示 message box，點擊確認後另開新分頁並且 redirect 到 OneAD Studio

❌ 剛建立但下拉未更新

  • 點擊 SELECT 會重新 fetch 列表，需做 debounce 防止短時間內重複點擊

🧭 素材管理頁導向 STUDIO 建立素材流程

➤ 使用左側選單路徑：

  1. 點擊左側 MENU BAR「素材管理」

  2. 進入後選擇 TAB：素材包

  3. 點擊「前往 Studio 建立素材」或「新增素材包」按鈕

▶ 若點擊「前往 Studio 建立素材」：

  • 顯示 Message Box： 將以開新視窗方式，帶您前往 STUDIO

  • 點擊【確認】

    • 表單抽屜關閉

    • 呼叫 /studio/redirect API 並開啟新視窗

  • OneAD Studio 驗證 token 成功後導入新增畫面

  • 回到 SuperDSP 後須手動重新整理頁面

▶ 若點擊「新增素材包」：

  • 顯示素材包表單：

    • 名稱、廣告品類、格式、素材上傳與備註

  • 若選擇 Studio 格式：

    • 顯示 Message Box 並提示前往 OneAD Studio

    • 點擊【確認】 → 另開 Studio 畫面

    • 點擊【取消】 → 留在 SuperDSP 畫面

🔔 注意事項

  • 所有 Studio 另開新視窗 redirect 動作需經過用戶手動確認

  • SuperDSP 無法主動偵測 Studio 中是否已有素材

操作流程（預覽 / 編輯 / 複製 / 建立） 

sequenceDiagram
    participant User
    participant SuperDSP
    participant API
    participant Studio
    User->>SuperDSP: 點擊「建立 / 預覽 / 編輯 / 複製」按鈕
    SuperDSP->>User: 顯示提示訊息
    User->>SuperDSP: 點選「是」
    SuperDSP->>API: 呼叫 /studio/redirect API（帶入操作類型）
    API-->>Studio: 透過 HTTP Redirect 跳轉至 STUDIO URL（含 token）
    Studio-->>User: 進入對應畫面（新增 / 預覽 / 編輯 / 複製）
