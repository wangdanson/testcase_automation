1

GET api/v1/superdsp/billing_report?company_id={id}&date={date}

  • 新增欄位：

    • insertion_order_id (IO 單 ID)

    • campaign_id(廣告活動 ID)

    • ad_group_id(廣告組合 ID)

    • transaction_type(交易模式)：回傳 固定價格 or 即時競價
      (用 campaign_type 判斷)

  • 排序邏輯：
    第一排序邏輯｜固定價格在前, 即時競價在後

    第二排序邏輯｜IO單 ID 由小至大, 由上至下排序

    第三排序邏輯｜廣告活動 ID 由小至大, 由上至下排序

    第四排序邏輯｜廣告組合 ID 由小至大, 由上至下排序
