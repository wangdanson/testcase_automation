📖 項目概述

📌 項目背景

在前一次 品牌安全 功能的基礎上，新增 內文比對 以豐富 pre-bid 廣告投放監控功能。

🎯 項目目標

  • 數據鎖定 增加「Environment」模式選項, 保留舊有「Audience」。

    • 「Audience」及「Environment」兩者擇一設定， 亦即不可同時啟用 。

      • 「Audience」選項內容：年齡、興趣特定議題、包含鎖定、排除鎖定

      • 「Environment」選項內容：包含內文比對、排除內文比對

      • 兩者一起設定會高機率面臨廣告投放不完的風險。

        • ODM 目前雖然可以兩者一起設定, 但 AOE 也知其風險, 還是切開 Placement 做設定為主

      • 上刊後，「Audience」及「Environment」不可以互相切換

        • 技術上可行, 但是報表呈現將難以解讀及解釋
          若切換之情境及數據說明：
          廣告活動 先用「Audience」執行
          數據收 segment 100 / 年齡 100
          切換「Environment」執行
          數據收 網站 100 / 年齡 100 + 年齡 100
          必須三個維度同時輸出, 才能看出 segment 100 / 網站 100 / 年齡 200 之間的關係

  • Placement Sequence 新增 內文比對 key contextual ( Sequences.json 欄位規格 )

  • ERP 設定介面 CUD 後，
    可同步更新 SuperDSP 與 ODM 兩系統的「品牌安全」及「內文比對」選項，資料兩者同源。

🧩 項目範圍

包含：

  • 數據鎖定新增兩個分類選項「Audience」及「Environment」

    • 「Audience」及「Environment」兩者擇一設定， 亦即不可同時啟用 。

    • 「Audience」選項內容皆能正常 CRUD，且 量體預估 及 報表輸出 等相關功能皆能正常運作

    • 「Environment」選項內容(包含內文比對、排除內文比對)皆能正常 CRUD。

  • 內文比對 Placement Sequence for SuperDSP 邏輯調整

    • key contextual 加入, 且能夠與 ad_server 正常溝通

  • ERP 設定介面可即時且同步更新 SuperDSP 及 ODM 兩系統的「品牌安全」及「內文比對」選項

不包含：

  • 品類 對於內文比對之差異：
    InStream “不開放”內文比對 ， RichMedia, Quality Traffic “開放”內文比對。

  • 合約 對於內文比對之差異：
    Media 合約“不開放”內文比對 ， Agency, Client 合約“開放”內文比對。

  • 內文比對 Placement Sequence for ODM 邏輯調整

    • 2024.12 已實現
