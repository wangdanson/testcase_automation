📖 項目概述

📌 項目背景

自 3 月上線後蒐集使用者回饋，PM 篩選緊急的改善需求，進行快速開發優化功能。

🎯 項目目標

  • admin 廣告主權限設定, 修改撈取邏輯

  • 受眾管理 > 廣告活動受眾包 擴充打包條件選項

🧩 項目範圍

包含：

  • admin 的角色包含：agency_admin / client_admin / media_admin

  • 受眾管理 > 廣告活動受眾包

不包含：

  • admin 的角色不包含：super_agency_admin / super_client_admin / super_media_admin / super_super_admin

  • 受眾管理 > 網站活動受眾包

🧑‍💼 目標受眾

用戶類型

  • ☑ 查看 受眾管理

並且可 建立 → 打包 → 被選擇 → 投放 整套流程正常運作。

驗收標準

新增廣告主時，admin 的廣告主權限需自動被加入

Agency_Admin / Client_Admin /
Media_Admin

在新增「廣告主」時，自動取得該廣告主的所有查看存取權限

以便能即時查看與管理新建立之廣告主的所有資訊，無需額外申請權限

高

  1. 當任一合約(Agency/Client/Media)下的任意帳號建立新「廣告主」後

  2. Admin 帳號（包含 agency_admin, client_admin, media_admin）重整頁面

  3. Admin 帳號應自動取得新建立之「廣告主」的所有查看存取權限

  4. 若廣告主停用，權限變更應立即生效，無需人工干預

廣告活動受眾打包，增加 Impression 事件（看過廣告）

SuperDSP 的 User
（具有受眾管理權限的用戶）

我需要在受眾管理 > 廣告活動受眾包中增加「看過廣告」的打包選項

以便能更精確地鎖定特定受眾群體，優化廣告投放效果

高

  1. 在「受眾管理 > 廣告活動受眾包」介面中，新增「看過廣告」的打包條件選項

  2. 用戶可以成功選擇「看過廣告」條件進行受眾打包<

  3. 用戶可以完成從建立 → 打包 → 被選擇 → 投放的整套流程

  4. 打包後的受眾資料能被正確儲存並在廣告投放時被調用

  5. 確保打包功能與其他現有條件選項相容，不產生衝突
