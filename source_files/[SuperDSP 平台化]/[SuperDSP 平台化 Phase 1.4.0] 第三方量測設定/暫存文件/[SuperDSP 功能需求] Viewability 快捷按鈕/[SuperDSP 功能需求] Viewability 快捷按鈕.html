Viewability 的使用情境會需要快速查看及修改，所以設計了以 Campaign 為視角的 CRUD 介面來讓使用者操作

  • 以 Campaign 為 Level 一次設定底下所有 Placement ？

  • 於廣告組合列表上方新增按鈕： (icon) 檢視 Viewability

  • 點擊後抽屜出現 檢視 Viewability 整體介面, 顯示所有 廣告組合資訊，並提供以下欄位：
    ( 此抽屜不做分頁, 把所有廣告組合依據建立日期由近至晚上至下排列 )
    ID: 101,000
    名稱：廣告組合的名稱
    類型：IAS, DoubleVerify, 無
    URL：https://…., 無
    功能：編輯

  • 點擊編輯，再展出一層抽屜 第三方量測設定 蓋住 檢視 Viewability

    • 標題：第三方量測設定
      副標：廣告組合名稱
      類型：必填, 下拉 IAS / Doublevarify
      JS URL：必填, http://….
