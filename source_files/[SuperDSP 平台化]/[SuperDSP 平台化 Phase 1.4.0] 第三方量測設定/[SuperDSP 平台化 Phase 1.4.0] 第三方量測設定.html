📖 項目概述

📌 項目背景

SuperDSP 上設定的廣告需要支援第三方量測，
客戶需求來自 4 家第三方公司：IAS / DoubleVerify / DCM / Neilson

針對 SuperDSP 的廣告進行可視量測的設定。這需要前端操作來新增追蹤區塊，並提供相應的設定介面。

🎯 項目目標

  1. 原本於素材包設定的 DCM / Neilson 追蹤碼功能，將整個功能移至廣告組合的第三方量測

  2. IAS / DoubleVerify / DCM / Neilson 四種第三方量測服務

  3. 提供友善的操作介面和資料驗證機制

  4. 確保量測設定能正確產出 xml 並做儲存

🧩 項目範圍

包含：

  • Edit/Create Ad Group 介面新增追蹤區塊和設定介面

  • 支援 IAS / DoubleVerify / DCM / Neilson 四種第三方量測服務

    • 廣告品類 RichMedia ＆ QualityTraffic：支援 IAS / DoubleVerify / DCM / Neilson

    • 廣告品類 Instream：支援 DCM / Neilson

  • JS 輸入驗證功能

不包含：

  • pre-roll 格式廣告的 VPAID 資料整合 (待定義)

  • 第三方素材進稿的處理流程

第三方量測模版詳情

第三方量測模版詳情

  • MTO 需準備 SuperDSP 用的第三方量測模版

  • IAS 需自動判斷格式以調整量測位置，參考模版 D 與 TextDrive 兩種模式

  • DV 只需一個模式

  • 量測時間固定在廣告曝光事件

  • 僅適用於非 pre-roll 格式

  • pre-roll 需要 IAS 和 DoubleVerify 產生 VPAID 資料，使用第三方素材進稿（待定義）

  • 輸入後，產生的資料會在 occ lxml 及查廣告的 lxml

🧾 非功能需求

  • 使用者介面需直觀易用

  • JS 驗證功能需提供明確的錯誤提示

  • 系統需要與現有的 occ lxml 及查廣告的 lxml 整合

  • 需參考 odm 目前實作方式

  • 響應時間需符合系統標準
