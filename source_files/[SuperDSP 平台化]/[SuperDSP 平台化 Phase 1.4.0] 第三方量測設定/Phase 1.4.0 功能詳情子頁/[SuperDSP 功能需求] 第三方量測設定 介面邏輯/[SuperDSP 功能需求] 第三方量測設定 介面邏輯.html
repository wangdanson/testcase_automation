  • 在 Create/Edit Ad Group 介面將 品牌安全 區塊移至 地區 與 第三方量測設定(i) 之間

  • 在 Create/Edit Ad Group 介面最下方新增 第三方量測設定(i) 區塊，點擊後顯示設定介面

    • 第三方量測設定(i) 區塊內所有欄位非必填

    • 說明文字 (i) ：請向第三方公司取得正確 URL 後再進行設定

    • 點擊 (x) 對該資料條 input 欄位內容做清除

    • 點擊各家量測公司 ( i )：顯示各家 URL 標準範本（詳細如下）

    • 輸入各家 URL：

      • 使用者可能會將引號連同 URL 一起貼上（如 "http://…"） 系統需自動辨識並移除多餘的引號

      • 輸入內容驗證機制：針對各廠商 URL 檢查是否包含 '必要資料'，
        若缺少 '必要資訊' 則顯示錯誤訊息提示使用者，且廣告組合此時將無法儲存

        • 已知限制：系統僅能檢查 URL 格式是否符合各廠商規範，但無法驗證追蹤碼是否實際有效。
          經多方討論決議，針對此限制不另行處理。
