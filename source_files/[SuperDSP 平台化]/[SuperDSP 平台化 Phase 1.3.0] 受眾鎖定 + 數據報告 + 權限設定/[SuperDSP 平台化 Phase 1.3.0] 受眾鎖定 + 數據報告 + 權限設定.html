    新增 編輯 支援 受眾鎖定的量體預估

呈上, 基於專案時間限制, 並考量國際公司 DPS 系統與 OneAD 當前技術架構的整合可能性,
將採用 年齡性別 為主要設定維度, 其他 Segment 則可以自由的複數疊加來做設計.

“量體預估” 核心計算邏輯：”年齡性別” 及 “Segment s ” 彼此是交集；“Segment” 與 “Segment” 彼此是連集

  • 廣告組合設定，所有數據類型說明：

    • 數據類型 ：底層類型｜SuperDSP 介面定義

    • 年齡性別 ：Tag｜維度

    • 興趣特定議題：Tag｜Segment

    • 特定族群 ：Pre-defined segment｜Segment

    • 產業鑽石受眾：Pre-defined segment｜Segment

    • 網站流量受眾：Self-defined segment｜Segment

    • 廣告活動受眾：Self-defined segment｜Segment

  • 排查 受眾管理 Segment 量體預估是否需要修改

    • 確認 [ 網站流量受眾包 / 廣告活動受眾包 ] 移除交集 [ 年齡性別＆興趣特定議題 ] 計算邏輯功能可正常運作

  • I/O單 placement level > 編輯 畫面讀取時, 預估量體 API 就會重新觸發

    • 意味著, 昨天的數據跟今天看到的數據會不一樣。(因為數據包每日更新)

  • 預估量體在 Placement oncue 當下儲存數值，上刊後除非該 Placement 異動 Segment ，否則預估量體 API 不會觸發

    • 意味著 I/O單 placement level > 編輯 初始畫面直接取用 DB 的 value

  • 最後結果 UU 數只取到千位數

    • 實際結果 222,123 ~ 225,666 UU
      顯示結果 222,000 ~ 225,000 UU

  • 假設 包含 群體很少， 排除 群體很多，上限值 < 10,000時, 導致預估量體計算結果為 < 10,000 (甚至負數)

    • 介面顯示結果為 0，於預估量體下方出現 警語：你的廣告受眾太過特定，可能影響廣告投放，建議將受眾目標設定較廣泛。

  • 包含 Segment 除了興趣特定議題以外, 其餘 4 項, 加總最多 100 個

    • 若超過, 出現 警語：選擇過多包含項目, 請減少選擇

  • 排除 Segment, 加總最多 50 個

    • 若超過, 出現 警語：選擇過多包含項目, 請減少選擇

  • 假設 包含 群體很少， 排除 群體很多，導致預估量體計算結果為 < 最小需求量體

    • 執行次數 * 頻次 ＝ 最小需求量體

    • 於預估量體下方出現 警語：你的廣告受眾太過特定，可能影響廣告投放，建議將受眾目標設定較廣泛。

    • 此階段先不開發， 未來投放策略優化加入 必定投放, ASAP…, 再全盤考慮

  • 量體預估計算邏輯說明

    • 年齡性別

      • 中華民國 戶政司 提供之人口數

    • 興趣特定議題

      • OneID 興趣特定議題比例

    • Segment 單體

      • Pre-defined - 每日凌晨做更新

        • 類型：特定族群 / 產業鑽石受眾

      • Self-defined - Oncue 期間, 每日凌晨做打包或更新

        • 類型：網站流量受眾 / 廣告活動受包

      • 如果 網站流量受眾 / 廣告活動受包 還未上刊

        • 情境一｜Pre-defined + 已打包 Self-defined： jimmy kuo 提供 API 算出

        • 情境二｜Pre-defined + 未打包 Self-defined：DB + jimmy kuo 提供 API 算出（參考下方 Step 展開含有未打包的範例）

    • Segment 與 Segment

      • jimmy kuo 提供 API 算出 Segment( s ) distinct 後 one_id 數量

額外邏輯1: 若包含無任何設定, 則必取戶政司數值, 不會出現 min[200萬, 0] = 0 的狀況
額外邏輯2: 若興趣無任何設定, 計算預估量體時, 視為全選, 但是DB儲存興趣選項為空, 讓介面與DB行爲一致


下限值計算式: (上限值 * 0.85X) - 排除uu

排除-已打包uu: [年齡 & (segment 排除已打包)] * 興趣 ratio, 大J SQL 
排除-未打包uu: [年齡 & (segment 排除未打包)] * 興趣 ratio, MASA 計算
排除uu: 兩者相加

備註: 排除 segment * 興趣 ratio 是為了預估量體計算式的合理性, 但實際投放並沒有交集興趣, 而是年齡 & segment 做投放

  • 帳號權限設定

    • 整體功能架構採自由彈性模式，可自行新增移除權限，並非綁死該角色僅有固定權限的方式
