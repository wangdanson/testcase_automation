2

廣告實名制
設定 > 廣告主管理 > 新增 編輯 廣告主

  • 增加 3 個欄位

    • 欄位名稱 1：實名制廣告主名稱

      • 必填欄位

      • 若 input 欄位為空, 右手邊有 [ 套用廣告主名稱 ] 字串

        • 點擊 [ 套用廣告主名稱 ] input 資料會同步 廣告主名稱

      • 若 input 欄位有值, 右手邊無 [ 套用廣告主名稱 ] 字串

    • 欄位名稱旁邊加入 , hover 後呈現文本

      • 文本：
        【實名制廣告主資訊】

        廣告將顯示您所填寫的實名制廣告主名稱，請輸入公司營業登記名稱。

        實名制廣告主指出資刊登廣告的個人或組織，依據台灣【詐欺犯罪危害防制條例】要求，網路平台須落實廣告實名制，並在發佈廣告時揭露相關資訊。

        SuperDSP 平台廣告投放將於廣告畫面右下角「OneAD Logo」中顯示以下資訊：

        廣告主：系統將顯示您於此欄位輸入的名稱

    • 欄位名稱 2：公司統一編號

      • 必填欄位

    • 欄位名稱 3：公司地址

      • 必填欄位

  • 點擊儲存時 Popup 訊息 及 兩個 Action

    • Popup 訊息：

      • 請確認實名制廣告主名稱是否正確。

        點擊廣告右下角「OneAD Logo」將顯示以下資訊：

        廣告主：OOOOO

    • Action 確認：執行儲存流程

    • Action 取消：退回編輯界面

  • 更新 實名制廣告主名稱 時與 oncue 的 Placement 關係

    • 該名稱被使用於 oncue 的 Placement, 會在每日更新 sequence 的時候做更新(意味著不會馬上即時更新)
