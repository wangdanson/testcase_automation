Overview

背景

  • 依據政府『詐欺犯罪危害防制條例』的要求，規定散播廣告時，需提供 受益人(委刊者) ＆ 出資者 資訊，新增 廣告主實名制 設定，來符合法規需求。

  • 代理商需要 IAS 七大安全鎖定 功能。

目標

  • 新增 廣告主實名制 功能

  • 新增 IAS-Prebid 功能

核心功能

  • N/A

目標使用者

  • External User

    • 類型：Client / Agency / Media

    • 角色：Admin / User

預期效益

  • 符合法規要求，降低違規風險。

  • 提升代理商使用意願。
