3.1 AII 報告概念說明 
  AII (Attention Impact Index) - 注意力衝擊指標

  AII 是衡量廣告格式「注意力效果」的指標，綜合考慮：
  - 注意力時間：用戶在廣告上的互動時長
  - 廣告格式特性：長寬比（aspect_ratio）、標準單價（default_vcpm）
  - 與標準格式的比較：以標準格式為基準進行標準化

  AII 計算公式：
  AII = (aspect_ratio × duration × default_vcpm) / (std_duration × std_vcpm)

3.4 執行流程：run 方法（行 35-62) 
def run
    # 1. 資料驗證
    if @placements.blank? || @events.blank?
      return {}
    end

    # 2. 重組事件數據：按 [group_type, id] 索引
    events_by_type = @events.index_by{|x| x.values_at('group_type', 'id') }
    events_by_type.default = Hash.new(0)

    # 3. 計算標準格式的基準值
    v1 = events_by_type[["ad_format_type_id", AII_STANDARD_AFT_ID]].
      values_at(*DURATION_EVENTS).sum
    v2 = events_by_type[["ad_format_type_id", AII_STANDARD_AFT_ID]].
      values_at(*COUNT_EVENTS).sum

    std_duration = (v1.to_f / v2)                  # 標準注意力時間 (毫秒)
    std_vcpm = @aft_by_id[AII_STANDARD_AFT_ID].default_vcpm  # 標準單價

    # 4. 按廣告格式加總 placements 的事件數據
    pcs_aii_sum_events = sum_pcs_events_by_aft(@placements, events_by_type)

    # 5. 計算活動的 AII (按格式分組)
    pcs_aii = calculate_pcs_aii(pcs_aii_sum_events, std_duration * std_vcpm)

    # 6. 計算各格式的 AII (benchmark)
    aft_aii = calculate_aft_aii(@aft_by_id.keys, events_by_type, std_duration * std_vcpm)

    # 7. 回傳結果
    {
      pcs_aii: pcs_aii,        # 活動各格式的 AII
      aft_aii: aft_aii,        # 各格式的 benchmark AII
      aft_by_id: @aft_by_id,   # 廣告格式資訊
    }
  end
3.5 關鍵方法分析 
sum_pcs_events_by_aft（行 67-95）

  作用： 按廣告格式分組，加總所有 placements 的事件數據。

  def sum_pcs_events_by_aft(pcs, events_by_type)
    pcs.group_by(&:ad_format_type_id).map do |aft_id, pcs|
      impact_duration, impact_counts = 0, 0
      cpe, imp, click = 0, 0, 0

      pcs.each do |pc|
        key = ['plaid', pc.id]
        if events_by_type[key]
          # 累加注意力時間
          impact_duration += events_by_type[key].values_at(*DURATION_EVENTS).sum
          # 累加注意力事件次數
          impact_counts += events_by_type[key].values_at(*COUNT_EVENTS).sum
          # 累加互動次數
          cpe += events_by_type[key]['cpe']
          # 累加曝光次數
          imp += events_by_type[key]['impression']
          # 累加點擊次數
          click += events_by_type[key].values_at('bannerClick', 'videoClick').sum
        end
      end

      {
        aft_id: aft_id,
        impact_duration: impact_duration,
        impact_counts: impact_counts,
        cpe: cpe,
        imp: imp,
        click: click,
      }
    end
  end

  calculate_pcs_aii（行 97-131）

  作用： 計算活動中各廣告格式的 AII 及相關指標。

  def calculate_pcs_aii(pcs_aii_sum_events, std)
    pcs_aii_sum_events.map do |data|
      aft_id = data[:aft_id]

      # 1. 計算平均注意力時間 (毫秒)
      duration = if data[:impact_counts].zero?
        0
      else
        data[:impact_duration].to_f / data[:impact_counts]
      end

      # 2. 計算 AII
      # AII = (aspect_ratio × duration × default_vcpm) / (std_duration × std_vcpm)
      aii = @aft_by_id[aft_id].aspect_ratio * duration * @aft_by_id[aft_id].default_vcpm
      aii /= std

      # 3. 計算互動率 (CPE Ratio)
      cpe_ratio = if data[:imp].zero?
        0
      else
        data[:cpe].to_f / data[:imp]
      end

      # 4. 計算點擊率 (Click Ratio)
      click_ratio = if data[:imp].zero?
        0
      else
        data[:click].to_f / data[:imp]
      end

      {
        aft_id: aft_id,
        duration: duration,
        cpe_ratio: cpe_ratio,
        click_ratio: click_ratio,
        aii: aii,
      }
    end
  end

  範例計算：
  # 假設標準值：
  std_duration = 500 (毫秒)
  std_vcpm = 100
  std = 500 * 100 = 50000

  # 橫幅廣告 (aft_id: 140)
  aspect_ratio = 0.8
  duration = 15000 / 35 = 428.57 (毫秒)
  default_vcpm = 80
  aii = (0.8 × 428.57 × 80) / 50000 = 0.549

  cpe_ratio = 50 / 2000 = 0.025 (2.5%)
  click_ratio = 18 / 2000 = 0.009 (0.9%)

  # 輸出
  {
    aft_id: 140,
    duration: 428.57,
    cpe_ratio: 0.025,
    click_ratio: 0.009,
    aii: 0.549
  }

  ---
  calculate_aft_aii（行 133-177）

  作用： 計算各廣告格式的 benchmark AII（不限於本次活動，是格式的整體表現）。

  與 calculate_pcs_aii 的差異：
  - calculate_pcs_aii: 使用本次活動的 placements 數據（key = ['plaid', pc.id]）
  - calculate_aft_aii: 使用廣告格式的總體數據（key = ['ad_format_type_id', aft_id]）

  def calculate_aft_aii(aft_ids, events_by_type, std)
    aft_ids.map do |aft_id|
      key = ['ad_format_type_id', aft_id]
      obj = events_by_type[key]

      data = {
        impact_duration: obj.values_at(*DURATION_EVENTS).sum,
        impact_counts: obj.values_at(*COUNT_EVENTS).sum,
        cpe: obj['cpe'],
        imp: obj['impression'],
        click: obj.values_at('bannerClick', 'videoClick').sum,
      }

      # 計算邏輯與 calculate_pcs_aii 相同
      duration = data[:impact_counts].zero? ? 0 : data[:impact_duration].to_f / data[:impact_counts]
      aii = (@aft_by_id[aft_id].aspect_ratio * duration * @aft_by_id[aft_id].default_vcpm) / std
      cpe_ratio = data[:imp].zero? ? 0 : data[:cpe].to_f / data[:imp]
      click_ratio = data[:imp].zero? ? 0 : data[:click].to_f / data[:imp]

      {
        aft_id: aft_id,
        duration: duration,
        cpe_ratio: cpe_ratio,
        click_ratio: click_ratio,
        aii: aii,
      }
    end
  end
