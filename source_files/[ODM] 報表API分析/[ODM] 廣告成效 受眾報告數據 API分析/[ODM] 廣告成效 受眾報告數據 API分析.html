  步驟 4: 轉換數據格式（行 44-63）

  原始結構是為了 Excel 輸出，需要轉換成前端 Table 格式：

  result = []

  cn_column_names = @formatted_one_campaign_data[:table_datas][0][:colnames]
  # ["年齡性別", "曝光次數(cv)", "可視曝光次數", "影片點擊次數", ...]

  @formatted_one_campaign_data[:table_datas][0][:data].each do |row|
    row_data = {}
    row.each_with_index do |column, index|
      if index == 0
        # 第一欄是維度值
        row_data[:target_name] = column
        next
      end
      # 反查 key: 從中文欄位名找回英文 key
      row_data[OdmReportConstant::TRANSLATION.key(cn_column_names[index])] = column
    end
    result << row_data
  end

  轉換過程範例：

  輸入（Excel 格式）：
  colnames: ["年齡性別", "曝光次數(cv)", "可視曝光次數", "影片點擊次數"]
  data: [

    ["female_35_44", 1200, 900, 60]
  ]

  處理邏輯：
  # 第一列處理
  row = ["male_25_34", 1000, 800, 50]

  # index = 0
  row_data[:target_name] = "male_25_34"

  # index = 1
  cn_column_names[1] = "曝光次數(cv)"
  TRANSLATION.key("曝光次數(cv)") = "cv"
  row_data["cv"] = 1000

  # index = 2
  cn_column_names[2] = "可視曝光次數"
  TRANSLATION.key("可視曝光次數") = "impression"
  row_data["impression"] = 800

  # index = 3
  cn_column_names[3] = "影片點擊次數"
  TRANSLATION.key("影片點擊次數") = "videoClick"
  row_data["videoClick"] = 50

  1. 支援的維度類型 

根據 OdmReportConstant::CLICKHOUSE_TARGET_TRANSLATION：

  | target_type 參數 | 中文名稱          | UseCase                            |
  |----------------|---------------|------------------------------------|
  | os             | 裝置            | ProcessOsDimensionUseCase          |
  | demographic    | 年齡性別          | ProcessDemographicDimensionUseCase |
  | product_key    | ProductKey 類別 | ProcessProductKeyDimensionUseCase  |
  | in_market      | In-Market 類別  | ProcessInMarketDimensionUseCase    |
  | segment        | Segment 類別    | ProcessSegmentDimensionUseCase     |
  | interest       | 興趣            | ProcessInterestDimensionUseCase    |
  | keyword        | 特定議題          | ProcessKeywordDimensionUseCase     |
  | pack           | 素材成效          | ProcessPackDimensionUseCase        |
  | media          | 媒體            | ProcessMediaDimensionUseCase       |

  每個維度都有對應的 UseCase 處理其特定的數據結構和邏輯。
