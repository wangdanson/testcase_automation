緣由

因應 OneAD 2025 策略佈局，RMN（Retail Media Network）已成為重點發展目標。

為了確保 RMN 媒體合作契約能夠符合現行市場需求，需要對當前的 Cue 表進行必要的內容調整。

目標

  • 匯出委刊單 及 Cue 表, 可以同時滿足 RMN / 操作型 / OneAD / 業務 四方操作情境需求

  • 藉由接單公司的切換, 委刊單 及 Cue 表可以切換不同的公司身份(LOGO / 檔名 / Header ….)做輸出

Cue 表
預估總廣告執行次數 欄位 內容異動

  • 若計價單位為 CPD, 則 預估總廣告執行次數 之 欄位內容為 數字(天)

  • 若計價單位為 CPT, 則 預估總廣告執行次數 之 欄位內容為 數字(趟)

  • 若計價單位為 除了 CPD / CPT 以外, 則 預估總廣告執行次數 之 欄位內容為 數字

  • 此欄位之數字計算邏輯是由 Excel 欄位的計算式得出, 並且對該格規範相應資料格式

    • 計算式： 廣告預算格子 / 單價格子

    • 計價單位 CPD / CPT 時, 為了呈現 數字(天) / 數字(趟) 資訊, 該欄位 資料格式需設為 "字串"

    • 計價單位 CPD / CPT 以外時, 呈現 數字 資訊, 該欄位 資料格式需設為 "數值"

      • 現階段就是設定為數值

  • 補充：經使用者會議討論, 不用把全部計價單位都加上中文單位 ex CPM(次), 因市場對於 CPT / CPD 較陌生, 所以僅針對 CPT / CPD 這兩個計價單位做額外說明
