POST 建立 Cross Channel Pixel

methods

POST

path 

api/v1/superdsp/cct_accounts

status

new api

request 

{
   "company_id": ${company_id},
   "name":"meta - pixel 1234",
   "channel_id":1,
   "tracking_id":"123456789123456",  // string
   "cct_product_category_id": 1,
   "event_names":[
      {
         "event_type_id": 15,
         "value":"superdsp_impression"
      },
   ],
}

controller

response 

{
   "success":true,
}

備註

  1. cct_product_category ： InStream / RichMedia Display Format / RichMedia Video Format

  2. event_names 的 value

    1. 驗證規則：（詳細規則請參考 slides）

      1. 僅可輸入英數字與底線，且必須以英文字母開頭

      2. 不同 channel 對應不同的字數限制

PUT 更新 Cross Channel Pixel

methods

PUT

path 

api/v1/superdsp/cct_accounts/${id}

status

new api

request 

{ 
  "name":"meta - pixel 1234",
   // "channel_id":1,
   "tracking_id":"123456789123456",  // string
   // "cct_product_category_id": 1,
   "event_names":[
      {
         "event_type_id": 15,
         "value":"superdsp_impression"
      },
   ],
}

controller

response 

{
   "success":true,
}

備註

  1. events

    1. rich_media_display ：只有 impression / click 兩種 events

    2. 排序：依照指定 id 順序 [1, 17, 7, 8, 9, 10]

  2. event_names 的 value

    1. 驗證規則：（詳細規則請參考 slides）

      1. 僅可輸入英數字與底線，且必須以英文字母開頭

      2. 不同 channel 對應不同的字數限制
