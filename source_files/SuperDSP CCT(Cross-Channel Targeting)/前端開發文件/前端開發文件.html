User Stories

Epic

作為一名使用者，我希望能夠在 SuperDSP 平台上設定與應用 Cross Channel Pixel，以便更精準地追蹤和優化我的廣告活動。

User Story 1：建立與編輯 Pixel

作為一名使用者，我希望能在 Cross Channel 頁面建立與管理 CCT Pixel，以便能維護可重複使用的追蹤資源。

Acceptance Criteria

  • 使用者可以進入 Cross Channel 頁面並看到 Pixel 列表（若有權限）。

  • 可透過搜尋輸入框，模糊搜尋 ID/Name/Channel/Pixel ID 欄位，篩選列表資料顯示。

  • 使用者可以依權限新增 / 編輯 Pixel：

    • 權限規則詳見 角色權限矩陣 。

  • 系統在表單操作時應提供必要驗證：

    • 驗證規則詳見表單驗證 test cases

  • 成功建立 / 編輯 Pixel 時，系統應提示成功訊息，並更新 Pixel 列表。

  • 若 API 或伺服器錯誤，系統顯示「」。

User Story 2：檢視 Pixel

作為一名使用者，我希望能在 Cross Channel 頁面檢視 Pixel，以便知悉目前已建立的追蹤資源。

Acceptance Criteria

  • 使用者進入 Cross Channel 頁面後，可以看到符合其角色權限的 Pixel 列表。

  • 權限不足的角色（read_only、brand_client）只能檢視，操作按鈕（新增 / 編輯）應隱藏。

  • media 角色不可存取 Cross Channel 頁面

    • 側邊 menu 選單不顯示 Cross Channel

    • 若嘗試進入，系統自動導轉回「IO 單管理頁」。

User Story 3：在 Ad Group 綁定 Pixel

作為一名使用者，我希望能在 Ad Group 建立或編輯流程中綁定 Pixel，以便正確追蹤該廣告組合的表現。

Acceptance Criteria

  • 使用者可以依權限新增 / 編輯 / 檢視 Ad Group。

  • 使用者可以在新增/編輯 Ad Group 時選擇已建立的 Pixel。

  • 使用者可以更換/移除綁定的 Pixel。

User Story 4：權限管理 - 管理 CCT 權限

作為一名管理者，我希望能在「設定」新增/編輯 使用者流程中管理 CCT 權限，以便能掌握不同角色的操作。

Acceptance Criteria

  • 使用者可以進入「設定」頁面，並看到「使用者管理」列表（若有權限）

  • 管理者可以依權限新增 / 編輯 admin 以下的使用者權限，並在「進階設定」管理 CCT 相關權限
