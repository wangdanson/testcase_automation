移除 Campaign / Ad Group 花費欄位顯示限制

開發項目 / 需求

[列表與 DashBoard] 移除 Campaign/Ad Group 花費顯示限制

系統

SuperDSP

Ticket Number

ITP-2877

開發人員

Ryan Meng

預估時間

描述

目前系統對「花費 (Spend)」欄位設有上限邏輯（花費不可超過預算），現需移除此顯示限制，以呈現實際的廣告投放金額（含超跑狀況）。

  • 影響範圍 ：廣告活動 (Campaign) 列表與 Dashboard、廣告組合 (Ad Group) 列表與 Dashboard。

  • 異動核心 ：解鎖顯示限制、新增 (i) Hover 提示、API 結構重構（Summary 物件）。

備註

為配合後續列表日期連動需求，需同步重構 API 結構，由後端直接提供靜態的 Dashboard 統計資訊，確保全局加總數據不受前端動態篩選影響。

功能細項

移除顯示限制

  • 移除「花費上限等於預算」之邏輯，改為顯示實際投放金額（例如預算 $1,000，實際花費 $1,050 則顯示 $1,050）。

  • 此調整須同時套用於 廣告活動 與 廣告組合 之列表與 Dashboard。

新增 Hover 提示

  • 於「花費 / Spend」欄位標題旁新增 (i) 提示圖示 。

    • zh : 花費為實際廣告投放花費，帳務認列以預算設定為主。

    • en : Spend reflects the actual ad delivery amount. Billing is based on the budget setting.

API 結構重構

  • 靜態 Dashboard 資訊 ：列表 API 需新增 dashboard 用的屬性，存放不隨列表分頁或動態過濾影響的總額數據。

  • 數據解耦 ：前端 Dashboard 元件須改為綁定此 API 靜態物件，不再透過前端列表加總計算。

  • 使用 requestV2 呼叫

[預算控制] 修正廣告群組停刊（ABORTED）後預算未釋放的問題

開發項目 / 需求

[預算控制] 修正廣告群組停刊（ABORTED）後預算未釋放的問題

系統

SuperDSP

Ticket Number

ITP-2921

開發人員

Ryan Meng

預估時間

描述

當廣告群組狀態變更為「停刊」（含 CLOSED 或 ABORTED ）後，系統計算 Campaign 總預算時，仍以該廣告群組原始設定的「預算總額（Budget）」而非「實際花費（Spent）」計算。這導致未用完的剩餘額度被鎖死，無法釋放回給同一個 Campaign 下的其他廣告群組使用。

  • 現狀 ：僅 CLOSED 狀態會釋放預算。

  • 問題 ：當狀態為 ABORTED 時，系統仍佔用完整預算額度。

備註

修正方案

需調整預算計算邏輯，將 ABORTED 狀態納入預算釋放條件中。當廣告群組停止運行後，應改以「實際花費（Budget Spent）」作為其佔用額度。

影響範圍

  • 預算計算 ：Campaign 總預算的可用額度（Available Budget）計算。

  • 檢核機制 ：新增或編輯廣告群組時，系統對預算上限的限制檢查邏輯。

  • 報表顯示 ：前端 Dashboard 中關於預算分配的佔用百分比。

功能細項

邏輯擴充

  • 修正預算計算公式，除原有的 CLOSED 狀態外，需將 ABORTED 狀態納入「釋放剩餘預算」的觸發條件。

額度釋放計算

  • 當廣告群組符合上述狀態時，該群組佔用的 Campaign 預算應從「原始設定金額 ( Budget )」調整為「實際已花費金額 ( Budget Spent )」。

可用餘額連動

  • 確保 Campaign 的「可用額度」能即時反映因群組停刊而釋放的差額，供其他廣告群組分配使用。

校驗同步

  • 新增 廣告群組時，預算限制檢查須採計釋放後的正確餘額。

  • 編輯 廣告群組時，剩餘預算的判斷邏輯須與此修正後的公式一致。

數據一致性

  • 確保此邏輯變更不影響過往已結束（ CLOSED ）廣告群組的預算顯示與計算基準。
