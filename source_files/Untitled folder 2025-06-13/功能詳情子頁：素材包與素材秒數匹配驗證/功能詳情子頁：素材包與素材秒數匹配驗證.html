功能一：素材秒數匹配驗證

📋 功能概述

基於ODM系統API數據，在用戶選擇素材包時即時驗證素材包中的素材秒數是否與基本資料中選定的素材秒數範圍匹配，防止成本錯配問題。

🎯 功能目標

  • 防止素材秒數與媒體供應商不匹配造成的成本浪費

  • 確保投放成本效益最佳化

  • 提供基於實際 API 數據的即時匹配狀態反饋

  • 與現有ODM系統無縫整合

API 整合驗證函數 

// 在Vue組件的methods中實作
methods: {
  // 從placement數據中獲取已選擇的素材秒數
  getSelectedDurationFromPlacement: function(placementData) {
    if (placementData && placementData.data && placementData.data.inventory) {
      return placementData.data.inventory.flv_second;
    }
    return 0;
  },
  
  // 從素材包數據中獲取素材秒數
  getMaterialDurationFromPack: function(packData) {
    if (packData.videos && packData.videos.length > 0) {
      return packData.videos[0].duration;
    }
    return 0;
  },
  
  // 根據具體秒數確定所屬範圍
  getDurationRange: function(duration) {
    if (duration <= 30) return "1-30";
    if (duration <= 60) return "31-60";
    if (duration <= 90) return "61-90";
    if (duration <= 120) return "91-120";
    return "121-150";
  },
  
  // 基於API數據的完整驗證函數
  validateMaterialPackageWithAPI: function(placementData, selectedPackData) {
    try {
      var selectedDuration = this.getSelectedDurationFromPlacement(placementData);
      var materialDuration = this.getMaterialDurationFromPack(selectedPackData);
      
      // 處理小數點秒數（無條件捨去）
      materialDuration = Math.floor(materialDuration);
      
      var durationRange = this.getDurationRange(selectedDuration);
      var rangeParts = durationRange.split('-');
      var minDuration = parseInt(rangeParts[0]);
      var maxDuration = parseInt(rangeParts[1]);
      
      var isValid = materialDuration >= minDuration && materialDuration <= maxDuration;
      
      var mismatchReason = '';
      if (!isValid) {
        if (materialDuration < minDuration) {
          mismatchReason = '素材秒數' + materialDuration + '秒小於選定範圍' + minDuration + '秒';
        } else {
          mismatchReason = '素材秒數' + materialDuration + '秒大於選定範圍' + maxDuration + '秒';
        }
      }
      
      return {
        isValid: isValid,
        selectedDuration: selectedDuration,
        materialDuration: materialDuration,
        selectedRange: durationRange + '秒',
        mismatchReason: mismatchReason,
        packInfo: {
          id: selectedPackData.id,
          title: selectedPackData.title,
          videoId: selectedPackData.videos[0].id,
          adFormat: selectedPackData.ad_format
        }
      };
    } catch (error) {
      console.error('驗證過程發生錯誤:', error);
      return this.getDefaultValidationResult(false, '驗證過程發生錯誤');
    }
  },
  
  // 默認驗證結果
  getDefaultValidationResult: function(isValid, reason) {
    return {
      isValid: isValid,
      selectedDuration: 0,
      materialDuration: 0,
      selectedRange: '未知',
      mismatchReason: reason || '未知錯誤',
      packInfo: {
        id: null,
        title: '未知',
        videoId: null,
        adFormat: '未知'
      }
    };
  }
}

功能二：Popup 警告視窗

📋 功能概述

當檢測到素材包與素材秒數不匹配時，立即彈出警告視窗，阻止用戶選擇並提供詳細的成本影響分析和操作建議。

🎯 功能目標

  • 即時阻止不當選擇，防止成本浪費

  • 提供清楚的成本風險說明和媒體供應商影響分析

  • 引導用戶做出正確決策

  • 提供具體的解決方案
