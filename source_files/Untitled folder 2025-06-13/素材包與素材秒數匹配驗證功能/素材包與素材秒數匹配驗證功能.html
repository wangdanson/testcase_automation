📖 項目概述

📌 項目背景

在 ODM 系統平台中，用戶在操作 placement 建立與編輯時會先選擇素材秒數（決定可選媒體與素材清單），然後在素材選擇階段設定綁定素材包。目前系統未針對用戶在基本資料中選擇的素材秒數進行素材包篩選，導致可能選擇到秒數不匹配的素材包。

核心問題：成本控制與媒體匹配

  • 不同素材秒數對應不同的賣價結構

  • 短秒數素材（如15秒）對應特定的短秒數媒體，成本較低

  • 長秒數素材（如30秒）對應不同的長秒數媒體，成本較高

  • 當操作人員誤用長秒數設定（如16-30秒）去投放短秒數素材（如15秒）時，系統會錯誤地選擇長秒數媒體進行投放

  • 這種不匹配導致實際投放成本遠高於預期，造成不必要的成本浪費

實際影響案例：

  • 素材實際長度：15秒（應使用短秒數媒體）

  • 操作人員設定：16-30秒範圍（系統選擇長秒數媒體）

  • 結果：投放成本按長秒數計費，但實際素材只有15秒，造成成本效益不佳

API數據結構說明：

  • Placement API 中的 inventory.flv_second 字段表示用戶選擇的素材秒數設定

  • Packs API 中的 videos[0].duration 字段表示素材包中實際素材的秒數

  • 素材包採用單一素材設計，每個素材包僅包含一個素材

🎯 項目目標

  • 成本控制 ：防止素材秒數與媒體不匹配造成的成本浪費

  • 精準投放 ：確保素材秒數與選定的媒體類型一致

  • 建立素材包與素材秒數的匹配驗證機制

  • 透過 popup 警告視窗提醒用戶不匹配問題

  • 防止用戶選擇不匹配的素材包，確保投放成本效益

  • 提升用戶操作體驗，減少錯誤選擇導致的財務損失

🧩 項目範圍

包含：

  • 基於實際 API 數據的素材包與素材秒數匹配驗證邏輯

  • Popup 警告視窗設計與實作

  • 阻止不匹配素材包選擇的功能

  • 錯誤提示與用戶引導機制

不包含：

  • 自動篩選素材包功能

  • 批量素材包驗證

  • 歷史數據修正功能

  • 媒體賣價結構調整

素材秒數匹配驗證邏輯

驗證規則：

  1. 通過 Placement API 獲取用戶在基本資料中選擇的素材秒數（ inventory.flv_second ）

  2. 通過 Packs API 獲取素材包中素材的實際秒數（ videos[0].duration ）

  3. 根據選定秒數確定對應的範圍區間

  4. 比對兩者是否匹配（素材包中的素材秒數需在選定範圍內）

  5. 不匹配時觸發警告機制

範圍區間定義：

  • 1-5秒範圍：包含1秒到5秒（1 ≤ 素材秒數 ≤ 5）

  • 6-15秒範圍：包含6秒到15秒（6 ≤ 素材秒數 ≤ 15）

  • 16-30秒範圍：包含16秒到30秒（16 ≤ 素材秒數 ≤ 30）

  • 31-60秒範圍：包含31秒到60秒（31 ≤ 素材秒數 ≤ 60）

  • 61-90秒範圍：包含61秒到90秒（61 ≤ 素材秒數 ≤ 90）

  • 91-120秒範圍：包含91秒到120秒（91 ≤ 素材秒數 ≤ 120）

  • 以此類推...

前端驗證邏輯範例： 

// 在Vue組件的methods中實作
methods: {
  // 從placement數據中獲取已選擇的素材秒數
  getSelectedDurationFromPlacement: function(placementData) {
    return placementData.data.inventory.flv_second;
  },
  
  // 從素材包數據中獲取素材秒數
  getMaterialDurationFromPack: function(packData) {
    if (packData.videos && packData.videos.length > 0) {
      return packData.videos[0].duration;
    }
    return 0;
  },
  
  // 根據具體秒數確定所屬範圍
  getDurationRange: function(duration) {
    if (duration <= 5) return "1-5";
    if (duration <= 15) return "6-15";
    if (duration <= 30) return "16-30";
    if (duration <= 60) return "31-60";
    if (duration <= 90) return "61-90";
    if (duration <= 120) return "91-120";
    return "121-150";
  },
  
  // 驗證素材包與選定秒數是否匹配
  validateMaterialPackageWithAPI: function(placementData, selectedPackData) {
    var selectedDuration = this.getSelectedDurationFromPlacement(placementData);
    var materialDuration = this.getMaterialDurationFromPack(selectedPackData);
    
    var durationRange = this.getDurationRange(selectedDuration);
    var rangeParts = durationRange.split('-');
    var minDuration = parseInt(rangeParts[0]);
    var maxDuration = parseInt(rangeParts[1]);
    
    var isValid = materialDuration >= minDuration && materialDuration <= maxDuration;
    
    var mismatchReason = '';
    if (!isValid) {
      if (materialDuration < minDuration) {
        mismatchReason = '素材秒數' + materialDuration + '秒小於選定範圍' + minDuration + '秒';
      } else {
        mismatchReason = '素材秒數' + materialDuration + '秒大於選定範圍' + maxDuration + '秒';
      }
    }
    
    return {
      isValid: isValid,
      selectedDuration: selectedDuration,
      materialDuration: materialDuration,
      selectedRange: durationRange + '秒',
      mismatchReason: mismatchReason,
      packInfo: {
        id: selectedPackData.id,
        title: selectedPackData.title,
        videoId: selectedPackData.videos[0].id
      }
    };
  }
}

特殊情況處理：

  1. API異常處理 ：

    • Placement API 無法訪問時的降級處理

    • Packs API 回應格式異常的容錯機制

  2. 數據完整性檢查 ：

    • inventory.flv_second 字段缺失的處理

    • videos 陣列為空的處理

    • 素材duration為0或負值的處理

  3. 邊界值素材 ：

    • 15秒素材選擇15秒設定：匹配（包含邊界值）

    • 15秒素材選擇16-30秒設定：不匹配

API整合規格

必要的API端點：

  1. Placement 詳情 API 

    GET /api/v1/odm/advertisers/{advertiser_id}/campaigns/{campaign_id}/placements/{placement_id}

    用途：獲取當前placement的素材秒數設定

  2. 素材包列表 API 

    GET /api/v1/odm/advertisers/{advertiser_id}/packs?flv_second={seconds}&ad_format_type_id={format_id}

    用途：獲取可用的素材包及其實際素材秒數

API 調用時序：

  1. 頁面載入時調用 Placement API 獲取基本設定

  2. 根據設定調用 Packs API 獲取可用素材包

  3. 用戶選擇素材包時進行即時驗證

  4. 如需修改範圍，重新調用 Packs API 獲取新的素材包列表

錯誤處理規範：

  • 404錯誤：顯示「找不到指定的 Placement 」

  • 403錯誤：顯示「沒有權限訪問此 Placement 」

  • 500錯誤：顯示「服務器內部錯誤，請稍後再試」

  • 網絡錯誤：顯示「網絡連接失敗，請檢查網絡設定」
