緣由

目前 AOE 人員需要在委刊單匯出後，手動將關鍵資訊複製到 Google 試算表中，以便掌握上刊進度與工作安排。

本系統將在 ODM 平台內建立自動化機制，當委刊單匯出後，自動擷取關鍵欄位資訊並呈現在統一的管理介面上。透過月份分類、日期排序等功能，讓廣告投手能在活動追蹤管理快速掌握所有委刊單狀態。

簡單來說,就是要將在Google功能搬到ODM中。

目前 AOE 手動更新的試算表

📦 統一術語說明

  • 委刊單 (Insertion Order, IO) ：客戶確認的廣告投放合約文件

  • ODM ：OneAD 內部的委刊單管理系統

  • AOE ：Advertisement Operations & Execution，廣告優化操作投放部門

  • 廣告投手 ：AOE 部門負責廣告投放操作的人員

  • 廣告組合 (Campaign) ：實際執行的廣告活動單位

  • Start Date ：委刊單的開始執行日期，作為月份歸屬和排序的依據

UserStory 與驗收標準

AOE 廣告投手視角

🔽 情境一：查看新匯出的委刊單

場景描述：AOE同仁在 ODM 系統中建立並匯出委刊單後，AOE 人員需要立即掌握這筆新的工作項目，以便安排後續的素材收集與上刊準備。

When 委刊單在 ODM 中被建立並匯出時
I want to 在活動追蹤介面立即看到這筆資料
So I can 及時安排廣告投放的準備工作

驗收標準

使用者操作

  • 頁面叫做“活動追蹤”

  • 建立時間點為Cue表的狀態為”已出委刊”

  • Cue表中1筆廣告預算將會產生1筆對應的活動追蹤資料

  • Google Sheet 欄位對應ODM Cue表來源

    • A: 委刊單編號

    • B: 接單業務

    • C: 產品

    • D :買法

    • 新增欄位: 買法備註

    • E: 廣告活動名稱

    • F: 廣告預算

    • G:廣告預算中的刊期起始

    • H:廣告預算中的刊期結束

    • I:版位名稱

    • J: 無,使用者手動選擇, 選項有1.已用印回簽 2.僅手簽(需補章) 3.僅信件確認, 預設為未選擇

    • K: 無,使用者自己勾選的欄位, 預設為未勾選

    • L: 無,使用者自己輸入的欄位, 預設為空白

1.點擊”匯出委刊單”按鈕

  • 用Tab方式區分 前月 當月 下一個月

  • 預設顯示當月資料

  • 第一順序活動 Start Date 排序, 第二順序為業務名稱

  • 以刊期初始日(G)判斷歸類在哪一個月份

1.進入 活動追蹤頁面

2.檢視資料

🔽 情境二：更新已存在的活動追蹤

場景描述：活動追蹤資訊可能因客戶需求變更或想更新資訊而需要調整。

When 想要更新資訊或客戶需求變更
I want to 編輯活動追蹤資料
So I can 根據最新資訊調整廣告投放策略

驗收標準

說明

使用者操作

  • 可以編輯的欄位

    • 預算,需要可以寫入文字或金額

    • 走期(起)

    • 走期(迄)

    • 回簽

    • 上刊

    • 備註

  • 除此以外欄位唯讀

  • Cue表更新了資料, 不會連動更新活動追蹤對應欄位資料

  • ODM 廣告活動更新Placement 不會連動更新活動追蹤資料

  • 備註不需要歷史紀錄

1.點擊活動追蹤頁面 某一筆資料的編輯按鈕

2.跳出編輯彈窗

3.送出

🔽 情境三：手動新增提醒類型

場景描述：某一個活動追蹤可能需要拆分成多個執行項目（如不同素材版本、不同投放策略），AOE 需要手動建立額外資料來管理這些細項。

When 需要為同一活動追蹤建立多個執行項目時, 或想建立一個提醒用活動追蹤
I want to 複製既有資料並修改部分欄位來建立新項目
So I can 更細緻地管理每個執行細項的進度

驗收標準

說明

使用者操作

  • 以下欄位沿用來源的資料

    • 編號

    • 負責業務

    • 產品

    • 買法

    • 買法備註

    • Campaign / Placement名稱

    • 格式

    • 回簽

  • 以下欄位讓使用者可在彈窗調整

    • 預算, 預設為“提醒用”文字,需要可以寫入文字或金額

    • 走期(起),預設為來源資料

    • 走期(迄),預設為來源資料

    • 上刊, 預設未勾選

    • 備註, 預設白

  • 新增提醒資料, 不需要連動Cue表或ODM活動資料

1.點擊某筆資料的「複製」按鈕

2.跳出複製用彈窗

3.送出

🔽 情境四：可以過濾活動追蹤資料

場景描述：在查看活動追蹤頁面需時想要可以過濾一定範圍資料。

When 需要快速找到活動追蹤資料
I want to 有過濾條件讓我可以勾選或調整過濾欄位後送出
So I can 快速找到想要的活動追蹤

驗收標準

使用者操作

  • 可以勾選(可複選)過濾的條件

    • 所有產品線

    • 所有業務

  • 可以調整的過濾條件

    • 走期(起) 的 一段日期區間

1.勾選或調整過濾欄位

2.點擊送出

  • 即時儲存

  • 自動記錄編輯者與時間

輸入備註內容

  • 顯示格式：[姓名 日期時間] 內容

  • 保留所有編輯記錄

查看備註歷史

🔽 情境五：已匯出的委刊單被新增內容或 被封存

場景描述：匯出的委刊單因為各種原因 被封存或新增/移除其中的廣告預算。

When 委刊單被封存, 或新增/移除廣告預算
I want to 能在活動追蹤列表明確標示, 或新增對應的活動追蹤資料
So I can 保留完整的工作記錄並避免混淆

驗收標準

使用者操作

  • 隸屬於此委刊單的所有活動追蹤資料將會在在頁面中顯示為“淺灰底”

  1. 封存了某筆Cue

  • 隸屬於此委刊單中該產品線的所有活動追蹤資料將會在在頁面中顯示為“淺灰底

  1. 編輯某筆“已出委刊單“ 或 “已拋轉”的Cue

  2. 移除了某個產品線

  3. 儲存

  • 該筆廣告預算對應的活動追蹤資料在頁面中顯示為“淺灰底”

  1. 編輯某筆“已出委刊單“ 或 “已拋轉”的Cue

  2. 移除了某筆廣告預算

  3. 儲存

  • 活動追蹤資料新增對應的資料

  1. 編輯某筆“已出委刊單“ 或 “已拋轉”的Cue

  2. 新增了某筆廣告預算

  3. 儲存
