廣告投放時匹配的順序：

  1. 獲取當前使用者 ID, 從 ID 得知對應的年齡性別, 興趣

受眾包有三種類型：興趣 / 廣告 / 網頁

  • 興趣受眾包

    • 使用者可以設定 年齡及興趣(必選)

      • DB 必定有值, 依設定值 id 帶入產 sequence

  • 廣告受眾包

    • 使用者無法設定 年齡及興趣,

      • DB 必為空值, 年齡及興趣以空值產 sequence
        當 sequence 年齡及興趣為空值時, SEO 會對全部 id 投放

  • 網頁受眾包

    • 使用者可以設定 年齡及興趣(非必選)

      • DB 若為空值, 年齡及興趣以空值產 sequence
        當 sequence 年齡及興趣為空值時, SEO 會對全部 id 投放

      • DB 若有數值, 依設定值 id 帶入產 sequence

    • ad_group 綁 網頁受眾包Ａ (網頁受眾包Ａ設定排除 網頁受眾包Ｂ)

      • 網頁受眾包Ａ條件 年齡 24-35, 34-45 電動
        網頁受眾包Ｂ條件 年齡 34-46, 保養

      • 僅將 網頁受眾包Ａ 年齡 24-35, 34-45 電動 條件帶入產 sequence,
        排除之受眾包各自年齡興趣條件不會涉入影響產 sequence.

Generate Sequence(TA) from DB relations

Diagram 描述在不同的系統, Sequence 是如何取用資料, 以及這些資料觸發產生的時機點

結論：

  • Generate Sequence(TA) 不管在 SuperDSP or ODM 系統,
    皆源自於 PreCampaignTargets CampaignTargetPids 這兩張表.

  • SuperDSP ODM 兩系統最大的差異在於,
    PreCampaignTargets CampaignTargetPids 這兩張表資料的 產生時機及觸發點不同

    • ODM 是先行的架構, 所以在 placement 產生以後, 後續兩張表的資料多為利用 ORM relation 達成

    • SuperDSP 為配合已有架構, 所以在很多地方是分開的, 直到關鍵步驟觸發才會做兩張表格同步
