排程更新受眾包

IP-2754 - 取得議題詳細資料... 狀態

  1. 先撈出 placement (條件：上刊, 暫停, 審核中, 結束日期小於等於今日) 綁定的受眾包

  2. 打 [get] api/v2/:source/segment-targeting 撈取受眾包 （system jwt token, role rd_manger） 

    response
{
  data: [
    {
      uuid: string,
      start_date: string,
      end_date: string,
      last_update_date: string,
      status: enum string ['未打包', '已打包']
    }
  ]
}

  3. 找出 受眾包 綁定的 placement 的 start_date, end_date, 取 [開始時間取最小, 結束時間取最大]

  4. 開始時間要-1, 取 placement 開始時間前一天去更新受眾包, 即受眾包需更新時間範圍

  5. 抓出來的時間範圍 需跟 撈取受眾包 做比對

    1. 如果沒有 uuid 就打 [post] api/v2/:source/segment-targeting 新增受眾包 API （建立這個受眾包的 user token）

    2. 如果有 uuid, 而且時間範圍需更新, 就直接打 [put] api/v2/:source/segment-targeting/:id 更新受眾包 API （system jwt token, role rd_manger）

    3. 時間範圍 在 撈取受眾包 的 start_date, end_date 裡，就不需要更新

      2. 判斷 受眾 uuid 是否匹配 撈取受眾包 API

      3. 判斷 該 uuid 是否”已打包”

      4. 判斷 最終打包日是否為今天或昨天
