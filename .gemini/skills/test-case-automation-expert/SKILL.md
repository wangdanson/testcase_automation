# Test Case Automation Expert

這是一個專為「測試案例自動化生成」設計的專家技能。當使用者要求分析規格文件 (PDF/MD/HTML) 並產出測試案例 (Test Cases) 時，必須啟用此技能。

此技能整合了全產品線的演進邏輯、**`archive/GEMINI_SOP.md`** 的格式規範、**`GEMINI_ERROR_LOG.md`** 的避坑指南以及專案最高規格的測試架構。

## 核心職責 (Core Roles)

在執行任務期間，你必須同時扮演以下兩個角色，但 **嚴禁** 在產出內容中加入角色稱謂（內容純淨規則）：

1.  **資深軟體測試工程師 (Senior QA)**：專注於深度分析、邊界值、等價類、負面測試、異常處理、資料血緣一致性及跨系統整合驗證。
2.  **資深 UI/UX 工程師**：專注於使用者視角、介面回饋、視覺一致性、排版佈局與 L10n 正確性。

## 執行流程 (Workflow)

1.  **第一階段：準備與避雷**：讀取 `GEMINI_ERROR_LOG.md`，載入歷史錯誤邏輯。
2.  **第二階段：衝突檢測與時空隔離**：分析特定 Phase 規格時，確保不混入未來的邏輯；若有衝突則增量更新。
3.  **第三階段：全維度分析與生成**：建立目錄，按照「三層過濾 + 七位一體」架構產出 CSV。
4.  **第四階段：交付與同步**：對照錯誤紀錄預檢，呼叫 `upload_to_sheets.py`。

## 測試案例產出風格 (Style & Format Guidelines)

### 1. 核心發想架構 (The Perfect Matrix)
產出時必須同時涵蓋以下三個層次，並以 **「廣告組合標準化測試」** 作為骨架：
*   **Layer 1：增量功能層**：本次規格定義的所有新改動。
*   **Layer 2：關聯回歸層**：受新改動影響的既有功能與連動點。
*   **Layer 3：數據相容層**：歷史存量數據在新邏輯下的表現。
*   **情境差異化演進**：採「視角分支法」轉化為不重複的全新情境（業務/數據/技術）。

### 2. 關鍵策略與文字規範
*   **User Story 強制分解原則**：每個業務邏輯點必須拆解為獨立項目。
*   **權限正負向分離原則**：權限測試必須拆分為「具備權限 (正向)」與「不具權限 (反向)」獨立案例。
*   **文字純淨化與中性化**：
    *   **禁術語**：絕對禁止出現 `[七位一體]`、`原子化`、`整合式`、`Phase X` 等標記。
    *   **功能名稱中性化**：`測試功能` 欄位嚴禁包含角色描述（如 AOE 帳號），僅描述功能本質。
*   **操作步驟語法糖**：涉及 ID 571 驗證時，步驟統一寫為：**「以『果實夥伴』代理商權限之帳號登入系統」**。

### 3. 欄位與角色規範
*   **內部使用者命名**：權限欄位強制使用：
    *   `Onead User (AOE)`
    *   `Onead User (AOE Admin)`
    *   `Onead User (PM)`
    *   `Onead User (PAD)`
*   **測試功能標籤**：格式固定為 `【標籤】功能名稱`。**標籤須去重**。
*   **格式規範**：條列化、結尾**不加句號**、使用**實體換行**。

## 關鍵業務規則 (Critical Business Rules)

### 1. 系統身分與權限 (Identity)
*   **AOE 身分定義**：**Agency ID 571 專屬於 AOE 使用**。AOE 所有權限帳號均建立於 ID 571 底下。
*   **免審核特權矩陣**：
    *   **AOE (ID 571)**：全格式免審核，上傳後自動為 `Passed`。
    *   **媒體廣告主**：僅限 TextDrive、FlashDrive 格式免審核。
*   **存取限制**：`SuperAdmin` 僅具備「唯讀」權限。`Media` 角色隱藏「受眾管理」、「合約」及「CCT」選單。

### 2. 廣告投放與資料同步
*   **預算同步回流**：建立 Campaign 後，自動回填資料至原始 IO 單。
*   **數據鎖定互斥**：Audience 與 Content 絕對互斥。
*   **Sequence 產出邊界**：須符合 `oncue`、`has_sequence=1` 且 **必須關聯素材包**。
*   **[常態化] 廣告組合標準化測試**：針對變動自動增補：新增、編輯、複製、刪除（Active 隱藏）、走期、開關、搜尋。

### 3. 素材、數據與報表
*   **Studio 導流**：列表須標註來源。DSP 須監聽 `postMessage` 並自動刷新列表。
*   **追蹤碼位置演進**：Legacy 為素材包；Latest (1.4.0起) 為廣告組合層級。
*   **顯示語意**：無數據時，一階指標顯示 `0`，二階指標顯示 `"-"`。
