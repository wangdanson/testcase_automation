Version( date_array )

  • example 

{
  40882:
  [
    {
      start_date: 2022-09-22,
      end_date: 2022-09-23,
      categories: [2, 5]
    },
    {
      start_date: 2022-09-23,
      end_date: 2022-09-30,
      categories: [20, 21]
    }
  ]
}

  • 如果沒有變更紀錄，直接抓現有紀錄

  • 如果有變更紀錄

    • 第一筆 

      {
  start_date: placement.start_date,
  end_date: 第一筆version建立的時間,
  categories: 修改前＋修改後 的categories
}

    • 最後一筆 

      {
  start_date: 最後一筆version建立的時間,
  end_date: placement.end_date,
  categories: 目前placement的設定
}

    • 中間歷程(如果有同一天進行修改， categories 要合併) 

      {
  start_date: 上一筆的start_date + 1day,
  end_date: version建立的時間,
  categories: version的設定(+同一天進行修改的categories)
}

資料計算邏輯

數據計算

  • 依據 version 將 daily row data 資料區分出來

    • example

      • 資料 id= 40882 && start_date>= 2022-09-22 && end_date<= 2022-09-23

      • 資料 categories in [2, 5, 20, 21] , 其他皆為 0 （others）

      • 所有項目(cv, impression…)數值都為 0 的資料直接剔除不用處理

  • 將 version 區分出來的 daily row data 資料進行權重計算

    • 將 others 數值依據權重分配給 categories

    • 權重計算公式： FLOOR(all_dataset * dataset / sum(dataset)) (所有數值加總*佔比)

    • example:

      • categories_id 2 cv 權重計算 = FLOOR((9968+9912+275) * 9968 / (9968+9912))=10105

      • categories_id 5 cv 權重計算 = FLOOR((9968+9912+275) * 9912 / (9968+9912))=10049

  • 將 version 區分出來的 group row data 資料與初步權重整理完的 daily row data 進行權重計算

    • 將 group row data 數值依據權重分配給 daily row data

    • 權重計算公式： FLOOR(group_dataset * daily_dataset / sum(daily_dataset)) (所有數值加總*佔比)

    • example:

      • categories_id 2 cv 權重計算 = FLOOR(42597 * 10105 / (10105+10049))=21357

      • categories_id 5 cv 權重計算 = FLOOR(42597 * 10049 / (10105+10049))=21239

  • 權重計算無條件捨去的差異值，需加到該 version 最小的數值

    • 找出該 version 相對應項目最小數值( Min(...) )

    • 將差異值加到該項目數值， Min(cv)+(group_dataset-sum(權重計算結果))= Min(cv)+(42597-(21357+21239))

    • 若有多筆相等的最小值，則將差異值依據 categories_id 排序小 -> 大，依序 +1 分配，直到差異值歸 0 為止

  • 將所有 version 的權重計算結果依據 tier_id ＆ categories_id & 項目(例如：cv)加總，作為 API response
