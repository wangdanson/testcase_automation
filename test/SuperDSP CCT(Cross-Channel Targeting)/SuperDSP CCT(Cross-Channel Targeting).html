緣由

在 SuperDSP 平台中，Cross Channel Targeting (CCT) 是一個獨立的物件，類似於 One Pixel，擁有自己的資料結構。此功能的開發是為了將資料同時打到不同的廣告平台，提升廣告投放的精準度和效果。

目的

  1. 提供一個統一的跨渠道目標設定介面，讓廣告主能夠更有效地管理和追蹤廣告活動。

  2. 支援多平台的 Pixel ID 管理，提升數據追蹤的準確性。

  3. 確保系統能夠支援多語言介面，滿足不同用戶的需求。

UserStory

  • 作為一名使用者，我希望能在 Cross Channel 頁面建立與管理 CCT Pixel，以便能維護可重複使用的追蹤資源。

  • 作為一名使用者，我希望能在 Cross Channel 頁面檢視 Pixel，以便知悉目前已建立的追蹤資源。

  • 作為一名使用者，我希望能在 Ad Group 建立或編輯流程中綁定 Pixel，以便正確追蹤該廣告組合的表現。

  • 作為一名管理者，我希望能在「設定」新增/編輯 使用者流程中管理 CCT 權限，以便能掌握不同角色的操作。

Wireframe

PPT by Helen

  1. 建立 Cross Channel Pixel

    • 使用者選擇平台 (Channel) 和輸入 Pixel ID。

    • 設定觸發事件類型 (Trigger Event Type)。

    • 輸入事件名稱 (Event Name)，並遵循輸入規則。

    • 點擊儲存，系統自動生成初始碼。

  2. 編輯 Cross Channel Pixel

    • 使用者可以編輯 Pixel ID 和事件設定，但無法更改 Channel。

    • 編輯完成後，點擊儲存，系統更新資料。

  3. 關聯到 Ad Group

    • 使用者在 Ad Group 中選擇要關聯的 CCT Pixel。

    • 系統檢查選擇的 Pixel 是否符合廣告格式要求。

    • 完成關聯後，系統更新 Ad Group 設定。
